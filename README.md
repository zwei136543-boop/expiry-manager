# 产品效期管理系统

一个专为连锁店铺设计的产品效期管理系统，帮助企业实时监控产品过期情况。

## 🎯 功能特性

- ✅ **多店铺管理** — 支持30家连锁店铺数据管理
- ✅ **预警规则** — 6个可自定义的预警时间段
- ✅ **数据导入** — 支持 Excel 和 CSV 格式批量导入
- ✅ **实时监控** — 统计卡片、店铺排行、紧急产品表
- ✅ **权限管理** — 管理员和店长两级权限
- ✅ **数据导出** — 导出为 Excel 文件
- ✅ **响应式设计** — 支持桌面和平板访问

## 🔐 功能说明

### 管理员功能
- 查看所有店铺数据
- 设置预警规则
- 管理店铺和店长账号
- 导入/导出数据
- 修改密码

### 店长功能
- 查看自己店铺的产品
- 手动添加产品
- 修改密码
- 导出自己店铺的数据

## 📝 使用指南

### 导入数据
1. 点击「导入数据」
2. 选择 Excel 文件
3. 系统自动验证店铺名称
4. 导入成功后自动更新统计

### 添加产品
1. 点击「添加产品」
2. 选择店铺、输入产品信息
3. 点击「保存」

### 修改密码
1. 点击顶部「修改密码」
2. 输入原密码和新密码
3. 点击「确认修改」
